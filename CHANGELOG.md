# Changelog

## 1.0.0

- Receive mail for your domain with Email Routing and an Email Worker; parse with postal-mime; store rows in D1 and bodies, raw messages, and attachments in R2.
- Address rules (aliases, catch-all, turned-off addresses), sender block list, optional forwarding.
- Send through the Cloudflare Email Service binding from any of your addresses; sent copies kept.
- Web inbox: folders, search, star, archive, trash, reply, forward, compose, address settings, keyboard shortcuts, phone layout, dark mode.
- Sandboxed HTML reading with remote images off by default; signed session cookie.
- GitHub Pages demo with an in-browser API.
